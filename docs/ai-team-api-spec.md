# 비켜줄래 - AI팀 API 요청 문서

## 배경

비켜줄래 앱은 GPS로 얻은 사용자 위치(행정구역 기준)를 바탕으로 침수 위험도를 보여주는 앱입니다.
현재 앱 화면에 표시되는 강수량 / 수위 / 위험도 데이터는 전부 목업(`Math.random()`)이며,
실제 서비스를 위해 아래 3가지가 AI팀 쪽에서 필요합니다.

- 홈 화면: 현재 강수량 / 수위 조회
- 결과 화면: 침수 위험도 분석
- 위험도 70 이상 시 알림 트리거

행동강령(상황별 대응 가이드), 주변 대피소 좌표는 다른 팀원이 별도로 작업하므로 범위 밖입니다.

---

## ① 홈 화면 - 현재 상태 조회

```
GET /api/current-status?lat={위도}&lng={경도}&region={지역}
```

| 파라미터 | 타입 | 설명 |
|---|---|---|
| `lat` / `lng` | number | GPS 좌표. **관측소/지역 매칭은 이 좌표 기준으로 처리** |
| `region` | string | 화면 표시용 도시명 텍스트 (예: "양주시", "경기도 용인시 기흥구"). 지역마다 행정구역 단계가 달라 포맷이 일정하지 않으므로 매칭에는 사용하지 말 것 |

**응답**
```json
{
  "currentRainfall": 22,
  "currentWaterLevel": 2.4,
  "updatedAt": "2026-08-12T14:30:00+09:00"
}
```

| 필드 | 타입 | 설명 |
|---|---|---|
| `currentRainfall` | number (mm/h) | 현재 강수량 |
| `currentWaterLevel` | number (m) | 현재 수위 |
| `updatedAt` | ISO 8601 datetime | 이 값이 언제 기준인지 (오래된 데이터일 경우 앱에서 경고 표시용) |

## ② 분석하기 버튼 - 위험도 분석

```
POST /api/flood-risk
Content-Type: application/json

{ "lat": 37.4979, "lng": 127.0276, "region": "서울특별시 강남구" }
```

| 필드 | 타입 | 설명 |
|---|---|---|
| `lat` / `lng` | number | GPS 좌표. **관측소/지역 매칭은 이 좌표 기준으로 처리** |
| `region` | string | 화면 표시용 도시명 텍스트. 매칭에는 사용하지 말 것 |

**응답**
```json
{
  "score": 72,
  "etaHours": 2,
  "rain1h": 18,
  "rain3h": 46,
  "waterLevelChange": 0.8
}
```

| 필드 | 타입 | 설명 |
|---|---|---|
| `score` | number (0~100) | AI 침수 위험도. 등급/라벨(안전·주의·위험)은 프론트에서 `score` 기준으로 자체 계산하므로 별도로 안 주셔도 됨 |
| `etaHours` | number (시간) | 위험 증가까지 예상 시간 |
| `rain1h` | number (mm) | 최근 1시간 강수량 |
| `rain3h` | number (mm) | 최근 3시간 누적 강수량 |
| `waterLevelChange` | number (m) | 수위 상승량 |

## ③ 위험도 70 이상 시 알림 트리거 (웹훅)

AI팀이 직접 사용자에게 알림을 보내는 게 아니라, **위험 지역 정보를 저희 쪽 푸시 서버로 전달**해주시면 됩니다.
실제 발송(대상자 조회 + Expo Push 호출)은 저희 푸시 서버가 처리합니다.

```
POST https://{저희-푸시서버-주소}/api/risk-alert
Authorization: Bearer {발급 예정인 API 키}
Content-Type: application/json

{
  "lat": 37.4979,
  "lng": 127.0276,
  "region": "서울특별시 강남구",
  "score": 72,
  "triggeredAt": "2026-08-12T14:30:00+09:00"
}
```

| 필드 | 타입 | 설명 |
|---|---|---|
| `lat` / `lng` | number | 위험 감지된 지점의 GPS 좌표. 저희 푸시서버가 이 좌표 기준으로 대상자를 매칭 |
| `region` | string | 화면/알림 표시용 도시명 텍스트 |
| `score` | number (0~100) | 트리거 시점의 위험도 |
| `triggeredAt` | ISO 8601 datetime | 70 이상으로 처음 넘어간 시각 |

**중요 - 호출 조건**
- 위험도가 **70 미만 → 70 이상으로 처음 넘어가는 순간에만** 호출해주세요.
- 이미 70 이상을 유지 중인 상태에서 재계산될 때마다 반복 호출하면 같은 지역 사용자에게 알림이 중복 발송됩니다 (스팸 방지).

**인증**
- 아무나 이 웹훅을 호출해 가짜 알림을 유발하지 못하도록, 고정된 API 키를 요청 헤더에 포함해주세요. 키는 저희가 발급해서 전달드리겠습니다.

**재시도 (선택)**
- 저희 서버가 일시적으로 응답 불가 상태일 경우 재시도 로직이 있는지 확인 부탁드립니다. 필수는 아닙니다.

## 확인 필요 사항

1. ~~`region` 포맷~~ → **해결**: `lat`/`lng` 좌표를 같이 보내드리기로 함. 관측소/지역 매칭은 좌표 기준, `region` 텍스트는 화면 표시 전용.
2. **데이터 갱신 주기**: 강수량/수위/위험도가 얼마나 자주 갱신되나요?
3. **배포 방식**: 직접 서버로 배포하실 예정인가요, 혹은 구글 시트(CSV publish) 방식도 가능한가요?
   - 시트 방식은 `region`이 행정구역 단위로 유한할 때만 가능합니다.
